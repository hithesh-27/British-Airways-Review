# British-Airways-Review

Project Overview
This project presents an interactive Tableau dashboard titled "British Airways Review" that visualizes customer reviews and key performance metrics of British Airways. The dashboard aims to provide insights into various factors affecting passenger experience, enabling users to explore metrics dynamically for better understanding of airline service quality and customer satisfaction.

Tools Used
Tableau for creating interactive data visualizations and dashboard.

Features
Interactive KPI cards displaying key metrics related to British Airways reviews.

Multiple filters for customized data exploration including:

Date/Month

Traveller Type

Seat Type

Aircraft Model

Geographic Region/Continent

Parameter control enabling selection of different metrics for detailed analysis.

User-friendly design optimized for clarity and engagement.

Data Source
The data used in this dashboard is sourced from publicly available British Airways customer reviews dataset, providing granular details on passenger feedback and ratings.

How to Use
Open the Tableau Public dashboard link.

Use the filters on the dashboard to narrow down the analysis based on your area of interest.

Explore different metrics using the provided controls to identify patterns and insights.

Hover over visual elements for detailed tooltips and explanations.

Purpose
This dashboard is useful for data analysts, aviation industry stakeholders, and passengers interested in understanding British Airways' service performance from customer feedback. It highlights key areas for potential improvement and strengths recognized by customers.
